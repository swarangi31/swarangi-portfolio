# Swarangi Nagdive — Cloud Portfolio

A simple professional portfolio website for GitHub Pages.

## Publish it
1. Create a new public GitHub repository, for example `swarangi-portfolio`.
2. Upload `index.html`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
4. GitHub will provide your public HTTPS portfolio URL.

Replace the LinkedIn placeholder in `index.html` with your real LinkedIn profile URL before publishing.
